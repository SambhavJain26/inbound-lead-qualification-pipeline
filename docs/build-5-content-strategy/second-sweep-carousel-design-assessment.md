# Five leasing carousels — second visual sweep

Date: 2026-09-17. User request: compare all five decks with the Build 01 and
Build 02 carousels, then apply the improvements. This records design changes and
technical QA, not user preference approval or permission to publish.

## What changed

The main improvement is how information is organized, not less information.
The previous export repeated grouped text blocks on 39 of 49 pages. That made
status comparisons, evidence fields and calculations feel like more paragraphs.
Those subjects now use comparisons, ruled records, prominent numerical results
or field worksheets. Quieter explanatory pages remain between them.

The package still contains thirteen posts: five carousels, six text posts and
two videos from one master recording. Deck lengths remain 10/9/9/11/10 pages.
All carousel captions, slide titles and scope footers are unchanged. All eight
non-carousel posts remain identical to the preserved editorial baseline.

Four bodies were lightly rephrased into explicit status or field labels. This
does not remove the method, change a calculation or introduce a new proof claim.
The model still never makes rental decisions. Mock, synthetic, sandbox and
proposed-production boundaries remain on the relevant public pages.

## Copy and annotation decisions

Only these canonical bodies changed: B5-01 page 7, B5-04 page 4, B5-06 page 9 and
B5-09 page 2. Scripts and HTML were updated together. Explicit field labels use
short nouns because they identify reusable records; padding them with transitional
copy would make the worksheets harder to scan. The copy pass kept direct actions,
plain language and concrete limitations, with no invented savings or customer quote.

Main-copy averages are now 25.4/27.1/26.8/28.3/27.7 words per page. All 49 pages
remain within the editorial review range of 20–35 words. This is a copy-balance
observation, not a quality score or proof of audience comprehension.

The annotation mix remains selective: blue boxes, underlines and circles provide
structure on cream; gold marks selected phrases and dark-page underlines. Quiet
pages are intentional. There is still only one navy page per deck. Serif type
inherits the normal title size rather than importing a giant opinion-slide payoff.
The body highlight spacing fix does not alter cover treatments or turn entire
paragraphs into highlight blocks.

## Remaining trade-offs and release boundary

These are practical reference documents, not maximally sparse opinion slides.
Some complete field labels and example explanations still wrap; reducing every
label to one line would lose meaning or require smaller body type. The screening
approval page remains one of the fuller compositions because its stage limitation
must stay alongside its examples. Readable scope footers sometimes take two lines.

The worksheets name fields and provide a method; the PDFs are not interactive,
fillable application forms. Decorative pen strokes should not be read as evidence
that a checklist has actually been completed.

The same visual family across five decks is deliberate. Variety comes from the
information structure, not a different brand on every page. A prospect-facing
publication check and the user's design preference review remain separate from
these technical tests. No deck was uploaded, scheduled or published; no live
workflow, account data, listing asset or reference project was changed.
